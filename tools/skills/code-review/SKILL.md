# 代码审查流程

## 硬性检查（逐条过，不要跳）
1. 边界条件：空输入、None、越界、除零
2. 异常处理：有没有裸 except？异常被静默吞掉了吗？
3. 资源释放：文件 / 连接有没有用 with？
4. 可变默认参数：`def f(x=[])` 是经典的坑

## 审查方法
1. **先完整读完文件再下结论**，不要看一段说一段
2. 引用具体行号，例如 `core/node.py:57`
3. 每个问题给出**为什么是问题**，并附一句修改建议

## 输出格式
- 严重问题（会导致 bug）
- 建议改进（风格 / 可读性）
- 结尾给一句总体结论
